# 🎬 MovieFlix

A modern iOS movie browsing application built with **Swift** and **UIKit**, following the **MVVM** architecture, clean code principles, and efficient memory management.

---

## 📱 Features

- 🎥 Browse trending and popular movies
- 🔍 Search movies by title
- 📄 View detailed movie information (rating, overview, release date)
- 🖼️ Async image loading with caching
- ⚡ Smooth and responsive UIKit interface
- 🔄 Loading states and error handling
- 🌙 Dark mode support

---

## 🏗️ Architecture

This project follows the **MVVM (Model–View–ViewModel)** pattern for clean separation of concerns.
